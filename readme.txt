The Easy Bookmark Plugin provides a bookmark solution for WP websites. Users can bookmark posts and view them anytime.

== Description ==

Easy Bookmark allows users to save posts or pages as bookmarks on your WP site. They can then access these bookmarked posts via a dedicated page or widget.

The plugin is ideal for users who want to save articles, blog posts, or products and revisit them later without needing to search again.

== Features ==

- Users can bookmark any post or page with a single click.
- Bookmark management with add/remove bookmark functionality.
- Display bookmarked posts in a widget or on a custom page.
- Simple shortcode to show the bookmark counter.
- Compatible with any theme.
- Works with posts and pages.
- Fully responsive and user-friendly.

== Frequently Asked Questions ==

= How do users bookmark a post? =
Users will see a "Bookmark" button on each post/page which they can click to add or remove a bookmark.

= Can bookmarks be displayed on a custom page? =
Yes, you can use the `[easy_bookmark_counter]` shortcode or a widget to display bookmarked posts on any page.

= Which content can visitors bookmark? =
Posts and pages. Choose which of the two the bookmark button appears on under Easy Bookmark > Settings.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/easy-bookmark` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Place the `[easy_bookmark_counter]` shortcode where you want to display the bookmarked posts.
